# Глоссарий

| Термин | Определение |
|---|---|
| **Сервер (нода)** | Удалённый VPS, управляемый панелью по SSH. |
| **Инстанс протокола** | Один развёрнутый контейнер протокола/сервиса на сервере (ключ вида `awg2`, `awg2__2`). |
| **Подключение (peer/клиент)** | Запись клиента внутри инстанса протокола; «peer» и «клиент» синонимичны «подключению». |
| **Владелец** | Пользователь панели, которому привязано подключение (`user_connections`). |
| **Эпоха учёта** | Идентификация физического peer'а (container ID, интерфейс, inode) для детекции сброса/пересоздания счётчиков. |
| **Exit-узел** | Сервер-egress: точка выхода трафика, отличная от сервера-entry (этап 3). |
| **Self-service** | Самостоятельное создание подключений пользователем роли `user` (этап 2). |
| **Audit trail** | Журнал значимых действий (таблица `audit_log` + зеркало в файле). |
| **Finalization** | Чтение финального счётчика удалённого peer'а и коммит дельты перед архивацией. |
| **Базлайн** | Зафиксированное значение счётчика на момент последнего успешного чтения; дельта считается от него. |
| **Tombstone** | Запись в `accounting_recoveries` об архивированном/удалённом peer'е с финальными счётчиками. |
| **operation_id** | Ключ идемпотентности мутаций (создание peer'а, restore, перенос групп). |
| **TOFU** | Trust-on-first-use: закрепление SSH-отпечатка хоста при первом подключении. |
| **Circuit breaker** | Отключение попыток SSH к ноде после серии неудач (с автовосстановлением). |
