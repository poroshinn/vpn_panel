# MVP-09: UI-каркас, SSE, i18n

**Веха:** M8 · **FR:** FR-3.13.1–3.13.8, FR-3.13.10–3.13.11, FR-3.14.1–3.14.4 · **Статус:** ✅ выполнено (2026-11-11)

## Цель
Единая дизайн-система, живые данные через SSE, локализация en/ru, страницы `/my`.

## Что сделать
1. Дизайн-система (FR-3.13.7): тёмная/светлая тема, SVG-иконки, адаптивность (мобильная
   раскладка, нижняя tab-панель по роли, компактный заголовок), Vanilla JS ES-модули.
2. SSE (FR-3.13.11): `/api/v1/events` — статусы серверов, прогресс операций, счётчики;
   автопереподключение; polling — fallback.
3. Страницы:
   - дашборд (карточки серверов, ping, статусы) — данные уже есть из MVP-05;
   - страница сервера (инстансы, peers, статистика хоста);
   - «Мои подключения» `/my` — просмотр и выгрузка конфигов/QR (FR-3.7.1 MVP-часть);
     самосервисное создание — Этап 2;
   - настройки — вкладки (внешний вид, CAPTCHA, бэкапы-заглушка, алерты-заглушка).
4. i18n (FR-3.14.x): ключи `app/i18n/{en,ru}.json`; fallback en; CLDR-плурализация ru;
   переключение cookie; даты/числа по локали, время UTC.
5. FR-3.13.10: `noindex`/robots для приватных страниц; кэш-политика статики; запрет
   кэширования ответов бэкапов.
6. Модальные окна: управление сервером, SSH-онбординг, страница входа.

## Тесты
- integration: SSE-поток отдаёт события и переподключается; i18n fallback; плурализация;
  `/my` показывает только свои подключения (user) — 403 на чужие.
- e2e (Playwright, если уже введён — иначе отложить): логин → дашборд → /my.

## Вне скоупа шага
PWA (этап 3), share-страница (MVP-10), самосервис (этап 2), графики учёта.

## Критерий приёмки
Все MVP-страницы навигируются; события приходят по SSE; язык переключается; `pytest -q`
зелёный.
